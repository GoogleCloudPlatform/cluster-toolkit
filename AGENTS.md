# Cluster Toolkit — Agent Instructions

This file is read by coding agents (Gemini CLI, Claude Code, Codex, Cursor, Copilot, etc.).

> **Scope:** The mandatory first-turn skill routing and operator safety invariants below apply to Cluster Toolkit **user and operator tasks** (creating/customizing blueprints and deployments, inspecting module inputs, outputs, `use:` wiring, and required GCP APIs under `modules/` or `community/modules/`, debugging GKE/Kueue workloads, and migrating XPK workflows). Repository maintainers explicitly tasked with authoring or refactoring Cluster Toolkit Go source (`cmd/`, `pkg/`, `tools/`) or editing module `.tf` implementation code when explicitly requested may read and edit `.tf` and Go source files normally; after pulling or editing Go/module source under `cmd/`, `pkg/`, or `modules/`, rebuild `./gcluster` with `make`.

## Mandatory First-Turn Skill Read (No Exceptions, Including Refusals & Confirmation Gates)

**BEFORE** answering, running any shell command, editing files, refusing an unsafe request, or emitting a `[PROPOSED REMEDIATION PLAN]` on an operator/user task, you **MUST** read (open) the matching `SKILL.md` on Turn 1:

1. **Cluster blueprints, modules & deployments** (`examples/`, `community/examples/`, `modules/`, `community/modules/`, module inputs/outputs/wiring/GCP APIs, `deployment.yaml`, `gcluster create/expand/explain/deploy/destroy`, Terraform or validator errors, deleting deployment folders) -> [`skills/cluster-blueprint-assistant/SKILL.md`](skills/cluster-blueprint-assistant/SKILL.md)
2. **Stuck GKE/Kueue workloads** (`Workload`, `ClusterQueue`, `LocalQueue`, `ResourceFlavor`, `Admitted: False`, `Inadmissible`, cohort borrowing, TAS, DWS `ProvisioningRequest`, queue/workload deletion) -> [`skills/gke-kueue-debugging/SKILL.md`](skills/gke-kueue-debugging/SKILL.md)
3. **XPK migration & GKE TPU/GPU job/cluster operations** (`xpk cluster`, `xpk workload`, `gcluster job submit`, failed `xpk` jobs, or emergency `xpk` pod/cluster deletion) -> [`skills/xpk-to-clustertoolkit/SKILL.md`](skills/xpk-to-clustertoolkit/SKILL.md)

See [`skills/README.md`](skills/README.md) for the full skill catalog. Always follow every rule in the loaded `SKILL.md`.

## Universal Safety Invariants (Details in Each `SKILL.md`)

These invariants apply even if the user asks otherwise—after reading the matching `SKILL.md`, refuse the conflicting step and explain why.

- **Never** run `terraform` directly (`init`, `validate`, `plan`, `apply`, `destroy`, `fmt`) for blueprint or deployment workflows; use `./gcluster` workflows (`test -x ./gcluster || make` when `./gcluster` is needed), and **never** bypass `gcluster` validators (`-l IGNORE`, `--validation-level IGNORE`, `--skip-validators`, `validation_level: IGNORE`).
- **Never** edit git-tracked templates under `examples/` or `community/examples/` in place, **never** edit generated deployment files (`.ghpc/`, `# DO NOT EDIT: Generated by gcluster`), and always include top-level `ai_assisted: true` in any new or copied Cluster Toolkit blueprint or deployment `.yaml` written to disk (excluding Kubernetes `apiVersion`/`kind` manifests).
- For blueprint and XPK tasks, **never** read `modules/**/*.tf` or `community/modules/**/*.tf` (`variables.tf`, `outputs.tf`, `main.tf`); use `./gcluster explain` and `catalog.yaml`.
- **Always** read the matching `SKILL.md` first to format a `[PROPOSED REMEDIATION PLAN]` (including `Blast Radius` and an explicit confirmation prompt awaiting `'yes'`) before any `./gcluster deploy`, `./gcluster destroy`, `./gcluster job submit`/`cancel`, `kubectl` mutators (`delete`, `patch`, `apply`, `edit`, `taint`, `rollout restart`), `rm -rf`, deleting user `.yaml` files, or reverting edits via `git checkout`/`restore`/`reset`/`clean`.
- Do only what was asked; report other warnings or issues you notice without fixing them unprompted.
