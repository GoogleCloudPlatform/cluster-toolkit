Contains utility scripts used by deploy and teardown scripts, which can also
be used by end-users to help with GCP administration tasks.

> **Note:** `deploy.sh` and `teardown.sh` call these scripts, so treat them as
> internal to those two. `service_account.sh` can also be run by hand; see the
> [Advanced Admin Guide](../docs/AdvancedAdmin.md#service-account-management).
